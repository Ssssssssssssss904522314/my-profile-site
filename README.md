# Личная страница — сайт-визитка

Статический сайт на HTML, CSS и JavaScript. Без сборки, серверной части и платных зависимостей. Подходит для GitHub и Vercel.

## Перед публикацией

Открой `index.html` и проверь/измени:

1. Имя и текст о себе.
2. Ссылки на свои проекты и реальные репозитории вместо демонстрационных `https://github.com/`.
3. Ссылку Telegram `https://t.me/` на `https://t.me/ВАШ_ЮЗЕРНЕЙМ`.
4. Заголовок страницы и описание в `<head>`.

Не добавляй секретные токены, пароли или API-ключи в файлы сайта.

## Публикация на Vercel

1. Открой [репозиторий на GitHub](https://github.com/Ssssssssssssss904522314/my-profile-site).
2. На Vercel нажми **Add New → Project** и импортируй этот репозиторий.
3. Для обычного статического сайта оставь Framework Preset как **Other**. Build Command и Output Directory можно оставить пустыми; Root Directory — `./`.
4. Нажми **Deploy**. После публикации Vercel выдаст ссылку `*.vercel.app`.

## Локальный просмотр

Просто открой `index.html` в браузере. Для тестирования как сайта можно также использовать расширение Live Server в редакторе кода.
